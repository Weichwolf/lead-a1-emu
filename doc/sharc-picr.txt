Programmable interrupt source routing reference

SharcPicr models PICR0..3 at native IOP2200..2203 (HWR2-3..5,A-14..18,
B-17). Nineteen logical priorities P0..18 each select a five-bit source.
PICR0/1/2 hold six fields at shifts0/5/10/15/20/25; PICR3 holds P18 at0.
Family reset words are0a418820,16a4a0e6,2307b9ac,00000012. This establishes
an explicit family reference, not a measured Nord reset or package identity.

All source inputs start unknown. Codes11,14,16,1e (hex) are disabled/LOW;
1f is software/HIGH. Every other code is a dynamic optional level, including
code0 (DAIHI). Clearing a software selection to0 therefore routes DAIHI;
it does not fabricate a universally deasserted interrupt. Optional false is
known LOW, not missing input. Source changes propagate through the committed
logical mux. destinations() returns priority bits, NOT core IMASK/IRPTL/
LIRPTL bit numbers. Repeated source selections can feed several priorities.
The mux does not itself latch, acknowledge, mask, arbitrate or enter a core
interrupt. Full DAI/DPI/core interrupt behavior remains separate work.

Delivered reads/writes retain all raw bits; unused upper fields do not create
phantom destinations. Reserved readback has no independent silicon proof.
Transactions stage register writes; outputs remain committed until commit.
Source events and snapshots reject active instructions. Snapshots retain
raw selectors and known/unknown inputs for independent restoration; dynamic
state on constant codes is malformed. Misaligned/wrong-width/out-of-window/
oversized accesses fail. A bound IOP bridge adds PC/address/operation context.
The logical selection is qualified at delivered accesses only; physical mux
settling, interrupt sampling latency and simultaneous rerouting/IRQ phase
remain unqualified. No undocumented PCLK delay is invented.

Owned tests check1824 independent source/destination/level cases using a
literal destination-field table and source classification. Reset words,
unknown/live inputs, software/disabled levels, duplicate routing, reserved
bits, separately restored state, transactions and malformed inputs are checked.
Fetched native4/5-write7/8-read cases verify source capture before later CPU
changes, actual mux effects, software selection, backend rollback and retry
without extra elapsed time. They do not qualify arbitrary native IRQ entry.

The original clocked reference now routes actual SPI completion events through
PICR's source1 selection before the already-qualified P1I latch/RTI path.
Other core priorities explicitly reject at this reference boundary. All other
unobserved peripheral source levels remain unknown. This event-boundary fixture
is not a complete level-sampling board interrupt controller.

Both transports in both images execute PICR0 read/CLR4c00/SET3000/write:
0a418820 ->0a418020 ->0a41b020 under the explicit family reset reference,
selecting DAILI for P2 while retaining SPIHI for P1. Transport0 first programs
PCG A/B but leaves them disabled (sharc-pcg.txt). Only transport1 clears
MODE1.RND32. Both set CBUFEN, save MODE1, initialize secondary B0/I0/L0/
R0/R2/R3/M8/M1 with image-specific command ring bases, then restore MODE1.
The B0 write establishes I0; there is no separate original I0 assignment in
this band. Main ringA=93ee1, part1 transport0=9235a, transport1=923f9;
ringB=A+80. Actual IDP_CTL0/CTL1 programming follows. All PCs/widths/results/
post-values are checked against original fields/PGR encodings, not recorded
emulator output, and independently corroborated by factual handoff6400242285.

Transport0/1 reach414/440 application instructions. All19 IDP setup
instructions now execute through real control/parameter owners: I0A/I0B,
M0=1,PC0=80, fresh CTL0 read/SETa0/write (sharc-idp-dma.txt). The actual
+933/+999 indexB retirement still checks three queued writes before their
real delivery. The next SYSCTL read/SET80 yields4->84 in USTAT1; the original
+961/+1027 write fails because peripheral DMA priority rotation is not yet
modeled. CPU/fetch, bus, receiver and controller remain unchanged on failure.
Four original programs at two serial cadences retain all earlier payload/
vector/SPI/SPORT/DAI checks. No SCLK, IDP data/grant, audio, boot or physical
result is invented.
