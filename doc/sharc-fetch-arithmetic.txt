Fetch-driven arithmetic loop contract

The native arithmetic frame remains the resource authority. The bound
transport adds fetched/fetched_draining phases and a marker on the last
retained real end instruction. Raw instruction-only retirement rejects
these phases: it cannot reconstruct their actual fetch history.

The end address in Fetch1 redirects the next cursor to the native PC-stack
start. Fetch1 at start+1 samples the old termination flags before the
current Execute instruction. FOREVER never samples arithmetic flags. On
termination the actual PC/loop resources pop, the next cursor becomes end+1,
and the two current F1/F2 words are suppressed when they reach Decode.
They become empty phases, not retired guest NOPs. Decode's retained end
is marked and follows checked D/A/E drain columns; older end retirements
still loop, and only that marked instruction finishes the native drain.
No fixed number of passes replaces
real instruction execution or RAM fetches.

Forward native setup still requires at least five instructions. A backward
setup can enter a nonwrapped multiple-instruction type0 frame after actual
PCSTK rewriting without reclassifying its apparent shorter body. Single,
wrapped, nested, mixed cache/stall/interrupt and termination-before-retained-
end paths remain guarded. Original self-modifying PM/cache and loop-IDLE/
interrupt composition require further qualification; this contract does
not establish final vector acceptance or instrument startup.

Primary constraints: PGRrev2.4 4-53/54 Table4-15,4-58,A-10/11.
The owned long-loop test uses all45 literal E/A/D/F2/F1 entries of the nine
Table4-15 columns, the manufacturer's numerical expectations and actual
resource-pop visibility. The short-loop test uses relocated owned backward
setup/PCSTK/DB instructions and independent first-/second-producer drain
expectations with native empty-LADDR/parent-PCSTK/depth readback.120 separate
RAM/controller/CPU/transport continuations cover occupied and retired Execute
phases. Further cases check SIMD AND/FOREVER with unresolved unsampled flags,
popped parallel PCSTK operands with flags changed
by the same instruction, unknown-condition rollback, missing/orphan end markers,
corrupted drain columns and actual PM/multiplier mixed-context rejection.

All eight optional original cases additionally retire the actual entry DB
after their8c08e setup checkpoint, then preserve the unchanged captured
loop-IDLE failure at CPU8c08f. First two body F1 addresses are accepted;
no IDLE has retired, no vector word has transferred and all384 DMA words
remain armed. The independent109318-cell final-payload oracle per cadence
is still checked. Separate instruction-only streams retain8c08e.
