Original emulator implementation: GPL-3.0-only (LICENSE).

The following project infrastructure is adapted from Weichwolf/blofeld-emu,
revision 057d3411b88b746c8bbf97c69958054e8a77d509, GPL-3.0-only:
  .clang-format, .clang-tidy, CMakePresets.json,
  cmake/Quality.cmake, cmake/Hardening.cmake and the GPL license text.
The GTK directory watcher follows the same public project's directory identity
and replacement-monitoring approach. The implementation is adapted for this
project's versioned parameter snapshot contract.
Source: https://github.com/Weichwolf/blofeld-emu
The one-instruction executor in src/arm/core/arm.cpp adapts that public project's
generic SLEIGH execution/ownership approach. patches/ghidra-byte-memory.patch retains its
correction for byte-backed memory. No HCS12 semantics or board behavior is reused.
No Blofeld firmware or manufacturer assets are copied.

LZO 2.10 / miniLZO, Markus F. X. J. Oberhumer, GPL-2.0-or-later:
  https://www.oberhumer.com/opensource/lzo/
  Pinned source archive: doc/dependencies.json; notice: LICENSES/LZO-GPL2.txt.
  Built statically with native dependency sanitizers and hardening. Upstream's
  LZO_CFG_NO_UNALIGNED=1 selects bytewise access without disabling sanitizer
  checks. No system-library fallback. Corresponding native source must accompany
  redistributable binary packages as required by its license.

Native SLEIGH / ARM5 specification, Ghidra 12.1.2, NSA and contributors:
  https://github.com/NationalSecurityAgency/ghidra
  Apache-2.0; notice: LICENSES/Apache-2.0.txt.
  reference/ghidra.json pins the release and consumed files. The byte-memory
  patch applies only to build copies. Native exceptions are its error interface
  and must stay outside future real-time audio callbacks. Retain corresponding
  source and notices when redistributing binaries as required by its license.

zlib 1.3.2, Jean-loup Gailly and Mark Adler:
  https://zlib.net/ ; Zlib license in LICENSES/Zlib.txt.
  Static SLEIGH dependency, pinned in doc/dependencies.json, built under native
  sanitizers/hardening with no system-library fallback.

Python and GTK4/PyGObject are host prerequisites, not vendored sources. Preserve
their licenses when packaging them. No DSP/audio dependency is integrated yet.

reference/1.36.json contains factual official download identities also recorded
by the private lead-a1-src reconstruction project; it contains no program bytes.
Official manuals, firmware and derived manufacturer assets remain local inputs.
